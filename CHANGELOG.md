# Changelog

Все значимые изменения в этом проекте будут документированы в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] - 2026-03-06

### Изменено
- Обновлена интеграция с 1С:Напарник под актуальный стандарт потоковых SSE-ответов API
- Добавлена поддержка потоков с `reasoning_content`, `tool_calls`, `choices`, multi-line `data:` events и финальных completed-сообщений
- Для справочного режима по умолчанию включен `skill_name=raw`, чтобы получать прямой финальный ответ без незавершённых внутренних tool-flow
- Исправлен формат авторизации для токенов 1С:Напарник: заголовок `Authorization` теперь отправляется в исходном виде токена

### Добавлено
- Поддержка чтения токена из файла секрета через `ONEC_AI_TOKEN_FILE`
- Скрипт `scripts/prepare-token-secret.sh` для миграции токена из `.env` в `.secrets/onec_ai_token`
- Docker Compose конфигурация для работы через локальный secret-файл
- Подключение контейнера к внешней сети `infra` для песочницы из `SteelMorgan/1c-agent-based-dev-framework`
- Unit-тесты для SSE-парсинга новых сценариев ответов 1С:Напарник

### Документация
- Обновлены инструкции по безопасному хранению токена
- Добавлены инструкции по сети `infra` и запуску в песочнице `1c-agent-based-dev-framework`

## [1.0.0] - 2025-01-07

### Добавлено
- 🎯 **MCP Protocol Support** - Полная поддержка протокола MCP для интеграции с AI ассистентами
- 🤖 **1С:Напарник Integration** - Прямая интеграция с API 1С:Напарник через правильные endpoints
- ⚡ **SSE Support** - Поддержка Server-Sent Events для real-time коммуникации
- 🌐 **REST API** - Дополнительные REST endpoints для прямого взаимодействия
- 📚 **Swagger UI** - Интерактивная документация API
- 🐳 **Docker Ready** - Готовые Docker конфигурации для развертывания
- 🔐 **Авторизация** - Поддержка Bearer токенов для 1С:Напарник API

### MCP Инструменты
- `ask_1c_ai` - Задать вопрос ИИ 1С:Напарник
- `explain_1c_syntax` - Объяснить синтаксис элемента 1С
- `check_1c_code` - Проверить код 1С на ошибки

### Docker и развертывание
- 🐳 **Dockerfile.build** - Многоэтапная сборка для production
- 🐳 **docker-compose.yml** - Базовая конфигурация для разработки
- 🐳 **docker-compose.prod.yml** - Полноценная production конфигурация
- 📊 **Мониторинг** - Prometheus + Grafana + Loki
- 🔄 **Автоматизация** - Скрипты развертывания для Linux/macOS/Windows
- 💾 **Резервное копирование** - Автоматическое создание бэкапов

### Документация
- 📖 **README.md** - Подробное руководство пользователя
